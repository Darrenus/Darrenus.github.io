# RONG — 观测与求证

星盘为主要母题：稳定的基准、可转动的指针，以及每次对准后可阅读的记录。万神殿提供光与停顿的参考，不复制建筑外形。保留原网站暗背景与工程气质，让项目与经历成为明确可达的内容。

## 形式法则与实现

| 法则 | 数字转译 | 实现参数 |
| --- | --- | --- |
| 共同中心与可度量的分区 | 六个主题共享旋转中心 | SVG 520 × 520，外圈半径 246，主题半径 184，主题间隔 60°；120 道刻度 |
| 底盘稳定，读数变化 | 固定刻度、旋转指针、公开记录 | ObservationDial；每个主题 2–3 条真实项目或经历，来源集中在 observations.ts |
| 低亮金属只在边缘反光 | 金属与正文分开设色 | 基底 #101310、刻度 #8F784F、可读黄铜字 #BAA477、正文 #ECE7DB；颜色是对间接光下氧化黄铜的设计近似，非实物测色 |
| 上方入光，表面安静 | 局部顶部径向渐变与接触阴影 | 指针外无持续旋转；问答输入框阴影 0 2px 6px #0003，无玻璃模糊 |
| 观察、对准、读取 | 签名交互“同轴取证” | 拖动、点击、键盘共用六主题状态；松手对齐最近刻度；问答 URL 预填草稿，不自动发送 |
| 信息按层次展开 | 身份 → 仪器 → 记录 → 项目 | 桌面主区 4 : 5.2 : 2.8，24px 间隔，最大 1280px；1190px 以下记录移至底部，760px 以下单栏，手机边距 24px |
| 装饰只在关系处出现 | 指针与 2–3 条证据线，项目概念图 | 连线只指示策展关系，不声称科学量值；照片与古典纹样不作贴图 |
| 运动有阻尼，阅读有停顿 | 松手后自然减速，短段驻留 | 指针 480ms cubic-bezier(.16,1,.3,1)，证据渐入 420ms；结尾段 130svh 容器 / 90svh sticky；手机与 reduced-motion 取消驻留 |

字体：自托管 IBM Plex Sans 400/500、IBM Plex Mono 400；中文优先系统苹方 / Noto Sans CJK SC。标题 28–64px，阅读正文 15–16px、行高 1.8–2；仪器辅助标注独立缩小。

## 内容与功能边界

- content/ 与 public/corpus/ 的个人事实、指标、专利状态保持原样。
- 项目、简历、PDF、404 与问答路由保留。
- 问答保留原 transport、来源、停止、重置与音效控制；有配置/无配置状态都明确展示。
- 履历来源支持具体段落锚点；缓存恢复保留提问参数与 hash。
- 减少动态效果时，无指针过渡、无证据渐入、无滚动驻留；问答页签图标也停止旋转。
